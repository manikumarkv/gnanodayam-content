# Fact review grades (archived)

Before reader review (gnanodayam #156–#160) went live, every sourced figure and chart in the
"Know more" docs was graded on a private review page by how weak its source looked. That page is
retired (gnanodayam #163); the grades are kept here for reference in
[`fact-review-grades.csv`](./fact-review-grades.csv) — 1,628 figures as of October 2026. No
manual reviews had been recorded on it.

Figures are now checked by readers ("Looks right" / "Report") and fixed from the app's
**Admin → Reader reports** page.

## Tiers

| Tier | Meaning | Reasons used | Count |
| ---- | ------- | ------------ | ----- |
| A — check first | The source is weak or the number may be off | Sources differ or derived (42) · Old data, 2019 or earlier (42) · Coaching / aggregator / wiki source (28) · Projection or target (14) · Recalled from memory (12) | 129 |
| B — check soon | A secondary report or an industry estimate | Secondary report or industry estimate | 622 |
| C — spot-check | An official or primary source (AISHE, ministry replies, official notices) | Official / primary source | 877 |

Columns in the CSV: tier, why, doc key, kind (fact / chart), label, value, source, date.
